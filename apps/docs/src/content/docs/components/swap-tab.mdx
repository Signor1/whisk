---
title: SwapTab
description: The same-chain swap surface, bundled inside WhiskSend or mounted on its own.
---

`<SwapTab>` is a same-chain token swap powered by App Kit's swap
routes. Two ways to use it: as the second tab of `<WhiskSend>`, or
standalone on a page where transfer isn't the point.

```tsx
import { SwapTab } from "@signordev/whisk-react";
```

## Standalone

```tsx
<SwapTab kitKey={process.env.NEXT_PUBLIC_CIRCLE_KIT_KEY!} defaultChain="Base" />
```

## Props

| Prop              | Type                            | Notes                |
| ----------------- | ------------------------------- | -------------------- |
| `kitKey`          | `string`                        | required             |
| `defaultChain`    | `Chain`                         | initial chain        |
| `defaultTokenIn`  | `Token`                         | initial source token |
| `defaultTokenOut` | `Token`                         | initial dest token   |
| `onSuccess`       | `(result: SwapSuccess) => void` |                      |
| `onError`         | `(error: Error) => void`        |                      |

## When to use which

| Surface                               | Use                                                    |
| ------------------------------------- | ------------------------------------------------------ |
| `<WhiskSend kitKey={...} />`          | Combined transfer + swap. The user picks via the tabs. |
| `<SwapTab kitKey={...} />` standalone | Swap-only pages.                                       |
| `useWhiskSwap()`                      | Custom UI; same engine, your components.               |

The hook version is in
[`useWhiskSwap`](/docs/hooks/use-whisk-swap).

## Getting a kit key

Sign in to [console.circle.com](https://console.circle.com), go to [keys](https://console.circle.com/api-keys), create a
kit key, copy and use it in your project. Without one,
the swap tab inside `<WhiskSend>` stays hidden.
