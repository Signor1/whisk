Whisk is a drop-in React component for sending and bridging USDC
across any chain App Kit ships with. It handles wallet connection,
recipient resolution, quote computation, gas estimation, signature
collection, transaction submission, and bridge confirmation — so you
can ship a stablecoin payment experience in your app in an afternoon.

## Install

<InstallCommand packages={["@signordev/whisk-react", "@signordev/whisk-core"]} />

## Quick start

```tsx
import { WhiskProvider, WhiskSend } from "@signordev/whisk-react";

export default function App() {
  return (
    <WhiskProvider projectId="your-app-kit-project-id">
      <WhiskSend />
    </WhiskProvider>
  );
}
```

That's the full integration. Drop it into a page, point the
`projectId` at your Circle App Kit project, and you're live.

## What's in this monorepo

- **`@signordev/whisk-core`** — chain-agnostic engine. State machine,
  CCTP routing, ENS resolution, quote computation. No React
  dependency.
- **`@signordev/whisk-react`** — the components and hooks. Styled
  `<WhiskSend />`, `<WhiskSwap />`, plus headless `useWhisk`,
  `useWhiskSwap`, `useWhiskAccount` for custom UI.
- **Five example apps** — e-commerce checkout, donate button, themed
  SaaS dashboard, payroll batch, invoice payment link. All under
  `examples/` in the repo.
