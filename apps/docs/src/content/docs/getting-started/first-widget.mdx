With the [provider mounted](/docs/getting-started/provider), this is
all you need to render a working transfer + bridge widget:

```tsx title="app/send/page.tsx"
"use client";

import { WhiskSend } from "@signordev/whisk-react";

export default function SendPage() {
  return (
    <main className="mx-auto max-w-md py-16">
      <WhiskSend />
    </main>
  );
}
```

Open the page and you'll see a "Connect wallet" card. Connect a
wallet and the widget walks through the rest:

<Steps>
  <Step>Pick a source chain, paste a recipient, type an amount.</Step>
  <Step>Whisk resolves the recipient (raw address or ENS name) against the destination chain.</Step>
  <Step>It builds a quote — same-chain transfer or CCTP bridge — and shows the fee breakdown.</Step>
  <Step>The user confirms. Whisk submits the transaction and renders a step rail (`authorize → burn → wait → mint`) for bridges.</Step>
  <Step>On success, you get a result card with the final tx hash and an explorer link.</Step>
</Steps>

## Listening to the flow

Three callbacks cover most analytics needs. They're stable, so you
can include them in `useEffect` deps without re-rendering:

```tsx
<WhiskSend
  onSuccess={({ quote, finalTxHash }) => {
    analytics.track("whisk.send.success", {
      amount: quote.amountIn,
      route: quote.route.kind,
      tx: finalTxHash,
    });
  }}
  onError={(error) => {
    analytics.track("whisk.send.error", {
      code: error.name,
      message: error.message,
    });
  }}
  onStateChange={(state) => {
    console.log("[whisk]", state.kind);
  }}
/>
```

`onStateChange` fires on every transition — including transient ones
like `resolving` and `quoting`. If you only care about terminal
states, gate it:

```tsx
onStateChange={(state) => {
  if (state.kind === "success" || state.kind === "error") {
    /* … */
  }
}}
```

## Adding swap

If you have a Circle Console kit key, pass it through and the swap
tab appears next to transfer. Without the key, the swap tab hides
itself:

```tsx
<WhiskSend
  kitKey={process.env.NEXT_PUBLIC_CIRCLE_KIT_KEY}
  tabs={["transfer", "swap"]}
  defaultTab="transfer"
/>
```

The two tabs share the same connection state, so connecting a wallet
once unlocks both surfaces.

## Where this falls short

`<WhiskSend>` is opinionated about layout — it's a card, it's
centred, it owns its width. If you need a different shape (sidebar
wizard, full-page checkout, sheet from the bottom), drop down to the
primitives. See [Components → Primitives](/docs/components/primitives).
